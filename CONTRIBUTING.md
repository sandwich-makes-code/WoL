# Contributing
Contributing to this repository needs a few guidelines before getting started.

All contributions WILL have to be in the Python language, small implications such as .txt files may be allowed.
If you’re contributing to the GUI version of the script, all GUI buttons and such HAVE to fit the size limit and the look of new GUI add-ons WILL have to use the SPECIFIED colour and font pack, which is listed below.

# Legacy continuation
I believe that all PCs should support my script, and we know not all of the Linux computers are as performant as others with our latest version.
So this community-supported version will keep the continuity of CLI while still keeping all the features of the GUI version.
Inside the Legacy Continuation folder, you will see template files to start building.
